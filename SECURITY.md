# Security Policy

## Scope

Sh4q is a discovery-only reconnaissance tool for authorised testing. Security
reports about the code, scope engine, network policy, evidence handling,
external adapters, or dependency behavior are welcome.

## Reporting a Suspected Issue

Please use a private GitHub security advisory or contact the repository
maintainer before publishing details. Include:

- Sh4q version or commit and environment details;
- a local fixture, offline test, or controlled target reproduction;
- expected scope decision and actual behavior;
- whether any network contact occurred; and
- a redacted trace or evidence excerpt.

Do not test suspected safety bypasses against unrelated live targets. Do not
include credentials, private scan databases, unredacted exports, or sensitive
target data in an issue or pull request.

## Supported Releases

The latest review release receives focused fixes. Older alpha releases may not
receive backports; upgrade before investigating a suspected issue.
